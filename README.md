### Вывод:
Легко заметить, что на небольших размерах CUDA работает даже хуже, чем последовательное умножение. Это можно объяснить расходами на передачу данных в GPU и инициализацию. Тем не менее, как только размеры матрицы увеличиваются, CUDA демонстрирует резкий рост производительности, и по своей эффективности становится сравнима с запуском программы на суперкомпьютере. 

Аномалии в данных (скачки времени при 2300–2500) могут быть связаны с оптимизациями работы видеопамяти или нагрузкой на систему. Таким образом, CUDA идеально подходит для ресурсоёмких вычислений.
