### Вывод:
 OpenMP ускоряет перемножение матриц начиная с размеров 200×200, давая выигрыш до 3х раз для больших матриц. На малых размерах (50×50, 100×100) ускорения нет из-за накладных расходов на создание потоков и конкуренции за память. По полученным результатам оптимальный порог для использования OpenMP — 200×200.
